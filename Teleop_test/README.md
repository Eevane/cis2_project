## Test different multilateral teleoperation architectures.
The scripts in the folder "Teleop_test" are executables for different teleoperation architectures. The naming convention is:
1) #ch means the number of channels;
2) P and F denote position and force channel;
3) The letters before 'P' represent the forward channel, while the letters after 'F' represent the backward channel;
4) for example, 3ch-FPF means three-channel architecture, forward force channel, backward position + force channel
